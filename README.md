# Proyecto Final KDD - Detección de Fraude Bancario
Proyecto final SINF-633 de UCenfotec.

## Objetivo
Aplicar las cinco etapas del modelo KDD para analizar transacciones bancarias e identificar posibles fraudes.

## Metodología
1. Selección de datos.
2. Preprocesamiento.
3. Transformación.
4. Minería de datos.
5. Interpretación y visualización.

## Algoritmos utilizados
- K-Means
- DBSCAN
- PCA
- Regresión logística
- Random Forest

## Resultados principales
La regresión logística alcanzó un recall de 86,4%, mientras que Random Forest obtuvo un F1-score de 0,872.

## Ejecución
1. Instalar las dependencias de requirements.txt.
2. Colocar transacciones_bancarias.csv en la carpeta /content/ de Google Colab.
3. Abrir Proyecto_KDD_Fraude.ipynb.
4. Ejecutar todas las celdas en orden.
